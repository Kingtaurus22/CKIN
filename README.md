# CKIN
CKIN adalah aplikasi berbasis web yang bertujuan untuk membantu calon penyewa kos mendapatkan informasi dan melakukan survei kos tanpa harus datang langsung ke lokasi. 

Platform ini menghubungkan User (calon penyewa kos) dengan Surveyor (orang yang menyediakan jasa survei kos). User dapat memilih lokasi survei, menentukan jumlah kos yang ingin disurvei, memilih jenis layanan survei, mengisi kebutuhan survei, menentukan tanggal survei, dan melakukan pembayaran. Surveyor dapat melihat pesanan berdasarkan domisili dan coverage area yang dimiliki. Surveyor kemudian melakukan survei secara langsung dan memberikan laporan hasil survei kepada User. 

Platform juga menyediakan fitur komunikasi antara User dan Surveyor, status pesanan, pembayaran, serta fitur booking kos setelah proses survei selesai.
